יסודות התקשורת - שכבה 3 (Network Layer)

מהו ניתוב (Routing) ואיך נתב מקבל החלטות?

ניתוב הוא התהליך שבו נתב (Router) מקבל חבילת מידע (IP Packet) ממשק אחד ומעביר אותה לממשק היציאה המתאים בדרך לשרת או מחשב היעד ברשת אחרת. כדי לעשות זאת, הנתב נעזר ב-טבלת הניתוב (Routing Table) – "מפת דרכים" המוחזקת בזיכרון ה-RAM שלו.

מבנה הנתונים

אנטומיה של טבלת ניתוב

כל רשומה בטבלת הניתוב כוללת מידע קריטי המאפשר לנתב לדעת לאן להפנות את התעבורה:

1. רשת היעד (Destination Subnet): כתובת ה-IP ומסכת רשת היעד.
2. הצעד הבא (Next-Hop IP) / ממשק יציאה (Exit Interface): לאן לשלוח את החבילה.
3. מקור המסלול (Prefix Code): מאיפה הנתב למד את הדרך (C=מחובר, S=סטטי, O=OSPF).
4. AD & Metric: אמינות המקור ועלות המסלול [AD/Cost].
מנגנון ההחלטה

איך הנתב בוחר נתיב?

כשחבילה מגיעה לנתב, הוא פועל לפי 2 חוקי ברזל נוקשים:

🎯 1. Longest Prefix Match (התאמה הספציפית ביותר) הנתב מעדיף תמיד את הכלל הספציפי ביותר! למשל, אם מגיעה חבילה ל-10.1.1.5, והטבלה מכילה נתיב ל-10.1.0.0/16 ונתיב ל-10.1.1.0/24 – הנתב יבחר ב-/24 כי הוא ספציפי יותר!
🏆 2. Administrative Distance - AD (מרחק מינהלי) אם לנתב יש שני מסלולים לאותה רשת בדיוק ממקורות שונים, הוא יבחר במקור עם ה-AD הנמוך ביותר (סטטי = 1, OSPF = 110, RIP = 120).
ניתוב מוגדר ידנית

ניתוב סטטי (Static Routing) ו-Default Route

בניתוב סטטי, מנהל הרשת מגדיר באופן ידני את הנתיב לכל רשת מרוחקת. פתרון זה מעולה לרשתות קטנות, לקישורי קצה, או להגדרת **Default Route (נתיב ברירת מחדל)** המפנה את כל התעבורה הבלתי מוכרת אל האינטרנט.

יתרונות ניתוב סטטי

  • אינו צורך משאבי מעבד וזיכרון בנתב.
  • בטיחות מירבית - אין חילופי הודעות ברשת.
  • שליטה מלאה ומודרכת של מנהל הרשת.

חסרונות ניתוב סטטי

  • אינו קונוורג'נטי - לא משתקם אוטומטית כשתקלה מתרחשת!
  • תחזוקה כבדה ומסורבלת ברשתות בינוניות וגדולות.
  • סכנה גבוהה לטעויות אנוש.
Cisco IOS CLI - Static & Default Routing
Router(config)#

! 1. הגדרת נתיב סטטי לרשת ספציפית דרך IP של הצעד הבא (Next-Hop)

Router(config)# ip route 192.168.20.0 255.255.255.0 10.0.0.2

! 2. הגדרת נתיב סטטי דרך ממשק יציאה מקומי (Exit Interface)

Router(config)# ip route 192.168.30.0 255.255.255.0 GigabitEthernet0/0/1

! 3. הגדרת נתיב ברירת מחדל (Default Route) - שולח כל תעבורה לא ידועה לאינטרנט/ספק

Router(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1

שדרוג מניתוב סטטי לדינמי

למה אנחנו חייבים פרוטוקולי ניתוב דינמיים?

בפרק הקודם למדנו על ניתוב סטטי – הגדרה ידנית של נתיבים. אך מה קורה ברשת בעלת מאות נתבים כשכבל נחתך או שנתב קורס? ניתוב סטטי מחייב את מנהל הרשת לקום באמצע הלילה ולעדכן ידנית את כל הטבלאות. פרוטוקול ניתוב דינמי מאפשר לנתבים "לדבר" זה עם זה, ללמוד את הטופולוגיה אוטומטית, ולחשב מסלול חלופי תוך שברירי שנייה!

פרוטוקולי וקטור מרחק

Distance Vector (DV)

נתב הפועל בשיטה זו מכיר רק את השכנים הישירים שלו. הוא שומע מהם "שמועות" לגבי הרשתות הרחוקות ומאמין להן. הוא אינו מחזיק במפה של כל הרשת.

📐 מטריקה (מדד לבחירת נתיב): ספירת קפיצות (Hop Count). הנתיב עם הכי פחות נתבים בדרך מנצח!
⏱️ עדכונים: עדכונים תקופתיים מלאים (משדר את כל טבלת הניתוב במרווחי זמן קבועים).
💡 דוגמאות מפורסמות: RIP (Routing Information Protocol), EIGRP (Cisco hybrid)
פרוטוקולי מצב הקישור

Link State (LS)

כל נתב בונה מפה מלאה ומדויקת של כל הרשת (כמו Google Maps/Waze). הוא יודע בדיוק איפה כל נתב נמצא, מה רוחב הפס של כל כבל, ומה מצב הקישורים.

📐 מטריקה (מדד לבחירת נתיב): עלות (Cost) – מחושבת על פי רוחב הפס (Bandwidth) של הקישורים. מהיר יותר = טוב יותר!
⏱️ עדכונים: עדכונים נקודתיים רק כשמתרחש שינוי בטופולוגיה (Triggered Updates/LSA).
💡 דוגמאות מפורסמות: OSPF (Open Shortest Path First), IS-IS

טבלת השוואה מרוכזת

קריטריון להשוואה Distance Vector (RIP) Link State (OSPF)
ידיעת הטופולוגיה מכיר רק שכנים ישירים (שמועות) מכיר מפה מלאה של כל הרשת
אלגוריתם חישוב מסלול Bellman-Ford Dijkstra (SPF - Shortest Path First)
מדד נתיב נבחר (Metric) ספירת קפיצות (Hop Count) עלות הקישור (Cost = 100Mbps / Bandwidth)
מהירות התכנסות (Convergence) איטית (עלול ליצור לולאות ניתוב) מהירה מאוד (כמעט מיידית)
צריכת משאבי מעבד וזיכרון נמוכה מאוד גבוהה (נדרש חישוב עץ SPF)
פרוטוקול הניתוב המוביל בעולם

צלילה לעומק: פרוטוקול OSPF

OSPF (Open Shortest Path First) הוא פרוטוקול Link State סטנדרטי ופתוח. הוא מבוסס על אלגוריתם דייקסטרה (Dijkstra) ומחלק את הרשת לאזורים (Areas) כדי לחסוך בחישובים. האזור המרכזי והחובה בכל רשת OSPF נקרא Area 0 (Backbone Area).

1. הודעות Hello

נתבים שולחים הודעות Hello קבועות כדי לגלות שכנים ולוודא שהם עדיין פעילים (Adjacency).

2. מסד נתונים LSDB

כל הודעות ה-LSA מאוחסנות ב-LSDB (Link State Database). מסד נתונים זה זהה לחלוטין בכל הנתבים באותו Area!

3. חישוב SPF

מתוך ה-LSDB, אלגוריתם דייקסטרה מחשב את העלות (Cost) הנמוכה ביותר לכל יעד ומכניס אותה לטבלת הניתוב.

Cisco IOS CLI - OSPF Configuration
Router(config)#

כדי להגדיר OSPF בנתב סיסקו, מפעילים את תהליך ה-OSPF בעזרת מזהה תהליך (Process ID) ואז מפרסמים את הרשתות המחוברות בעזרת **Wildcard Mask** ולא סאבנט מאסק רגיל!

! כניסה למצב הגדרת OSPF עם Process ID = 1

Router(config)# router ospf 1

! הגדרת מזהה ייחודי לנתב (מומלץ מאוד)

Router(config-router)# router-id 1.1.1.1

! פרסום הרשת 192.168.10.0/24 באזור Area 0 (Wildcard: 0.0.0.255)

Router(config-router)# network 192.168.10.0 0.0.0.255 area 0

! פרסום רשת ה-WAN 10.0.0.0/30 באזור Area 0 (Wildcard: 0.0.0.3)

Router(config-router)# network 10.0.0.0 0.0.0.3 area 0

💡 טיפ של מקצוענים (Wildcard Mask): Wildcard Mask הוא תמונת הראי של Subnet Mask. משיגים אותו על ידי חיסור כל אוקטט מ-255.255.255.255. למשל עבור 255.255.255.0, ה-Wildcard יהיה 0.0.0.255.

איך OSPF נראה בתוך טבלת הניתוב? (show ip route)

כשמריצים את הפקודה show ip route בנתב, נתיב שנלמד דרך OSPF יסומן באות O.

Router# show ip route

Codes: C - connected, S - static, O - OSPF, R - RIP...

Gateway of last resort is not set

10.0.0.0/8 is subnetted, 2 subnets

C 10.0.0.0/30 is directly connected, GigabitEthernet0/0

O 172.16.1.0/24 [110/65] via 10.0.0.2, 00:04:12, GigabitEthernet0/0

C 192.168.10.0/24 is directly connected, GigabitEthernet0/1

Administrative Distance (AD) = 110 מדד האמינות של הפרוטוקול. ברירת המחדל של OSPF היא 110 (לעומת 120 ב-RIP ו-1 בניתוב סטטי). נמוך יותר = אמין יותר!
Metric / Cost = 65 העלות הכוללת להגעה ליעד. מחושבת על פי סיכום העלויות של כל הקישורים בדרך.

תרגיל מעשי: מלחמת הפרוטוקולים - RIP מול OSPF

Cisco CLI Cheat-Sheet

פקודות חשובות בנושא ניתוב

פקודות הצגה ודיאגנוסטיקה (Show & Test)

show ip route - הצגת טבלת הניתוב המלאה של הנתב.

show ip route ospf - הצגת נתיבי OSPF בלבד.

show ip ospf neighbor - הצגת שחור השכנים של OSPF ומצבם.

show ip interface brief - בדיקת סטטוס וכתובות ה-IP בממשקים.

traceroute [IP] - מעקב אחר נתיב החבילה תחנה אחר תחנה.

פקודות הגדרה (Configuration)

ip route [net] [mask] [next-hop] - הגדרת נתיב סטטי.

ip route 0.0.0.0 0.0.0.0 [next-hop] - הגדרת נתיב ברירת מחדל.

router ospf [process-id] - כניסה להגדרת OSPF.

network [net] [wildcard] area [id] - שיוך רשת ל-OSPF.

passive-interface [int] - מניעת שליחת עדכונים לממשק פנימי.
